# RiderGuild Beta — Правила сообщества / Community Guidelines

**Русский | English**

## Русский

RiderGuild Beta — публичное пространство для тестирования приложения, обсуждения идей и обмена обратной связью.

### Основные правила

- Общайтесь уважительно и по существу.
- Не допускаются оскорбления, угрозы, травля, дискриминация и целенаправленное преследование участников.
- Не публикуйте чужие личные данные без разрешения.
- Не размещайте номера телефонов, точные текущие координаты, токены, ключи, пароли, приватные переписки и другие чувствительные данные.
- Не публикуйте спам, рекламу, вредоносные файлы или ссылки.
- Для багов используйте Bug report, для предложений — Feature request, для общих вопросов — Discussions.
- Проблемы безопасности не публикуйте открыто: используйте закрытое сообщение об уязвимости через GitHub Security.
- При тестировании SOS, Live Location и функций геолокации не создавайте опасных ситуаций на дороге и не отвлекайтесь от управления мотоциклом.

### Модерация

Сообщения и материалы, нарушающие эти правила, могут быть скрыты или удалены. При повторных или серьёзных нарушениях доступ к участию в публичном сообществе может быть ограничен.

## English

RiderGuild Beta is a public space for testing the app, discussing ideas, and sharing feedback.

### Core rules

- Communicate respectfully and stay on topic.
- Harassment, threats, abuse, discrimination, and targeted intimidation are not allowed.
- Do not publish another person's private information without permission.
- Do not post phone numbers, precise current location coordinates, tokens, keys, passwords, private conversations, or other sensitive data.
- Do not post spam, advertising, malicious files, or malicious links.
- Use Bug report for bugs, Feature request for improvements, and Discussions for general questions.
- Do not disclose security issues publicly; use GitHub private vulnerability reporting.
- When testing SOS, Live Location, or geolocation features, do not create unsafe road situations or interact with the app while riding.

### Moderation

Content that violates these rules may be hidden or removed. Repeated or serious violations may result in restrictions on participation in the public community.
