# RiderGuild Beta — FAQ

**Русский | English**

## Русский

### Это исходный код RiderGuild?

Нет. Этот репозиторий предназначен для публичного beta-тестирования. Исходный код приложения и backend здесь не публикуется.

### Где скачать APK?

APK публикуется в разделе **Releases**. Если там пока нет файла, значит публичная сборка ещё не загружена.

### Какая версия сейчас актуальна?

Текущая тестовая версия: **1.8.0-beta.11, build 40**.

### Можно ли устанавливать новую beta поверх старой?

Обычно да, если используется та же подпись приложения. Если Android не позволяет обновление, зафиксируйте точный текст ошибки и сообщите о нём тестовой группе.

### Где сообщать об ошибках?

В **GitHub Issues**. Для воспроизводимых проблем используйте шаблон Bug report.

### Где задавать обычные вопросы?

Для оперативного общения используется сообщество **RiderGuild | Beta Testers**. Подтверждённые баги лучше отдельно фиксировать в GitHub Issues.

### Можно ли публиковать скриншоты?

Да, если на них нет номеров телефонов, точных координат, приватных сообщений, токенов, паролей и других чувствительных данных.

### Можно ли тестировать SOS в реальной чрезвычайной ситуации?

Нет. Beta-тестирование SOS и Live Location проводите только в безопасных контролируемых условиях. Приложение в beta-версии не следует рассматривать как замену официальным экстренным службам.

### Нужно ли создавать новый Issue, если такая ошибка уже есть?

Нет. Лучше добавить полезную информацию к существующему Issue: модель телефона, Android, версию RiderGuild и точные условия воспроизведения.

## English

### Is this the RiderGuild source-code repository?

No. This repository is for public beta testing. The RiderGuild application source code and backend source code are not published here.

### Where can I download the APK?

APK builds are published in **Releases**. If no file is available there yet, the public build has not been uploaded yet.

### What is the current version?

Current test version: **1.8.0-beta.11, build 40**.

### Can I install a new beta over an older one?

Usually yes, as long as the application uses the same signing identity. If Android refuses the update, record the exact error message and report it to the testing group.

### Where should I report bugs?

Use **GitHub Issues** and the Bug report template for reproducible problems.

### Where should I ask general questions?

The **RiderGuild | Beta Testers** community is used for day-to-day communication. Confirmed bugs should preferably also be recorded in GitHub Issues.

### Can I attach screenshots?

Yes, as long as they do not contain phone numbers, precise coordinates, private messages, tokens, passwords, or other sensitive data.

### Should SOS be tested during a real emergency?

No. Test SOS and Live Location only in safe, controlled conditions. A beta build should not be treated as a replacement for official emergency services.

### Should I open a new Issue if the same bug is already reported?

No. Add useful details to the existing Issue instead, such as phone model, Android version, RiderGuild version, and exact reproduction conditions.
