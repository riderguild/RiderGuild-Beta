# RiderGuild Beta

**Русский | English**

Публичный центр beta-тестирования мобильного приложения **RiderGuild**.

> Этот репозиторий предназначен для тестеров. Исходный код RiderGuild здесь не публикуется.

## Русский

### Текущая тестовая версия

**RiderGuild 1.8.0-beta.11 — build 40**

RiderGuild находится в активной разработке. Beta-сборки могут содержать ошибки, незавершённые функции и изменения интерфейса.

### Что тестируем

- карту и геолокацию;
- клубы и сообщества;
- клубные места и точки на карте;
- маршруты;
- события;
- SOS и Live Location;
- уведомления;
- профиль пользователя и связанные сценарии коммуникации.

### Установка Android beta

APK-сборки будут публиковаться в разделе **Releases** этого репозитория.

1. Откройте **Releases**.
2. Выберите последнюю beta-версию.
3. Скачайте APK.
4. Разрешите установку приложений из этого источника, если Android запросит разрешение.
5. Установите APK поверх предыдущей beta-версии либо как новую установку.

Если в Releases пока нет APK, значит публичная сборка ещё не загружена.

### Как сообщить об ошибке

Откройте вкладку **Issues** и создайте новый Bug report. Перед созданием нового Issue проверьте, не описал ли уже кто-то такую же проблему.

Укажите версию RiderGuild и build, модель телефона, версию Android, шаги для воспроизведения, ожидаемое и фактическое поведение, повторяемость ошибки и при необходимости приложите скриншоты или запись экрана без личных данных.

### Важно для публичных отчётов

Не публикуйте в Issues номера телефонов, точные координаты текущего местоположения, токены, ключи, пароли, приватные переписки или скриншоты с чувствительными персональными данными.

## English

Public beta testing hub for the **RiderGuild** mobile app.

> This repository is intended for testers. RiderGuild source code is not published here.

### Current test version

**RiderGuild 1.8.0-beta.11 — build 40**

RiderGuild is under active development. Beta builds may contain bugs, unfinished features, and interface changes.

### What we are testing

- map and geolocation;
- clubs and communities;
- club locations and map points;
- routes;
- events;
- SOS and Live Location;
- notifications;
- user profile and related communication flows.

### Installing the Android beta

APK builds will be published in the repository **Releases** section.

1. Open **Releases**.
2. Select the latest beta version.
3. Download the APK.
4. Allow installation from this source if Android asks for permission.
5. Install the APK over the previous beta version or as a fresh installation.

If no APK is available in Releases yet, the public build has not been uploaded yet.

### Reporting a bug

Open the **Issues** tab and create a new Bug report. Before creating a new Issue, check whether the same problem has already been reported.

Include the RiderGuild version and build, phone model, Android version, reproduction steps, expected and actual behavior, whether the issue is reproducible, and screenshots or screen recordings when useful and free of personal data.

### Important for public reports

Do not publish phone numbers, precise current location coordinates, tokens, keys, passwords, private conversations, or screenshots containing sensitive personal data in Issues.
