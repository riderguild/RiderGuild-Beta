# RiderGuild Beta — приватность тестирования

RiderGuild использует функции, которым для работы могут требоваться данные пользователя, включая геолокацию, уведомления и предоставленную самим пользователем профильную информацию.

## Для тестеров

Во время beta-тестирования:

- предоставляйте разрешения Android только тем функциям, которые хотите проверить;
- не публикуйте чувствительные данные в публичных GitHub Issues;
- при отправке скриншотов проверяйте, что на них нет номеров телефонов, точных координат, приватных сообщений и других персональных данных;
- для сценариев SOS и Live Location используйте безопасные тестовые ситуации.

## Публичный репозиторий

Этот GitHub-репозиторий публичный. Всё, что вы публикуете в Issues, может быть доступно другим пользователям GitHub и посетителям интернета.

Исходный код, серверные конфигурации, ключи доступа и внутренние данные разработки RiderGuild в этом репозитории не публикуются.

Этот файл описывает правила публичного beta-тестирования и не заменяет полноценную юридическую политику конфиденциальности продукта.
