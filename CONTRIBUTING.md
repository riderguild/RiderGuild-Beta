# Участие в RiderGuild Beta / Contributing to RiderGuild Beta

**Русский | English**

## Русский

Этот публичный репозиторий предназначен прежде всего для **beta-тестирования**, а не для публикации исходного кода RiderGuild.

### Как помочь проекту

Самый полезный вклад тестера:

- воспроизвести ошибку и описать точные шаги через [Bug report](https://github.com/riderguild/RiderGuild-Beta/issues/new?template=bug_report.yml);
- подтвердить существующий Issue на другой модели телефона;
- сообщить версию Android и RiderGuild build;
- предложить улучшение через [Feature request](https://github.com/riderguild/RiderGuild-Beta/issues/new?template=feature_request.yml);
- проверить новую beta-сборку по [TESTING.md](TESTING.md);
- обсуждать общие вопросы и идеи в [Discussions](https://github.com/riderguild/RiderGuild-Beta/discussions);
- сообщить о неточности в публичной документации.

### Pull Requests

Pull Request уместен только для улучшения **публичной документации этого beta-репозитория**. Исходный код приложения и backend разрабатывается в закрытых рабочих репозиториях.

### Правила сообщества

Перед участием ознакомьтесь с [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

### Приватность и безопасность

Не помещайте в Issues, Discussions, комментарии и Pull Requests номера телефонов, точные текущие координаты, токены, ключи, пароли, приватные переписки или другие чувствительные данные.

Потенциальные проблемы безопасности не публикуйте открыто. Используйте [Private vulnerability reporting](https://github.com/riderguild/RiderGuild-Beta/security/advisories/new) и прочитайте [SECURITY.md](SECURITY.md).

## English

This public repository exists primarily for **beta testing**, not for publishing RiderGuild source code.

### How you can help

The most useful tester contributions are:

- reproduce a bug and provide exact steps through [Bug report](https://github.com/riderguild/RiderGuild-Beta/issues/new?template=bug_report.yml);
- confirm an existing Issue on another phone model;
- provide Android version and RiderGuild build information;
- suggest an improvement through [Feature request](https://github.com/riderguild/RiderGuild-Beta/issues/new?template=feature_request.yml);
- test a new beta build using [TESTING.md](TESTING.md);
- use [Discussions](https://github.com/riderguild/RiderGuild-Beta/discussions) for general questions and ideas;
- report inaccuracies in the public documentation.

### Pull Requests

Pull Requests are appropriate only for improvements to the **public documentation in this beta repository**. Application and backend source code is developed in private working repositories.

### Community guidelines

Before participating, please read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

### Privacy and security

Do not include phone numbers, precise current location coordinates, tokens, keys, passwords, private conversations, or other sensitive information in Issues, Discussions, comments, or Pull Requests.

Do not disclose potential security issues publicly. Use [Private vulnerability reporting](https://github.com/riderguild/RiderGuild-Beta/security/advisories/new) and read [SECURITY.md](SECURITY.md).
